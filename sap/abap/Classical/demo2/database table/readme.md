# Database Table

这是一个固定值表的示例。

## 项目

| 项目 | 内容说明 |
|---|---|
| MANDT | クライアント |
| NAME | バリアント変数名 |
| TYPE | 選択タイプ |
| NUMB | 現在の選択番号 |
| SIGN | 範囲データ型の行データ型: タイプ SIGN のコンポーネント |
| OPTI | 範囲データ型の行データ型のタイプ OPTION のコンポーネント |
| LOW | 選択バリアント: 項目内容(LOW/HIGH) |
| HIGH | 選択バリアント: 項目内容(LOW/HIGH) |

## 自定义 Data Elements

| Data Element | 内容说明 | 参照的 Domain |
|---|---|---|
| ZEVARI_NAME | バリアント変数名 | ZDVARI_NAME |
| ZESEL_TYPE | 選択タイプ | ZDSEL_TYPE |
| ZESEL_NUMB | 現在の選択番号 | ZDSEL_NUMB |
| ZEDDSIGN | 範囲データ型の行データ型: タイプ SIGN のコンポーネント | ZDDDSIGN |
| ZEDDOPTION | 範囲データ型の行データ型のタイプ OPTION のコンポーネント | ZDDDOPTION |
| ZEVARI_VAL_255 | 選択バリアント: 項目内容(LOW/HIGH) | ZDVARI_VAL_255 |
